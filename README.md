# safe coin — $SAFECOIN

drains, quantum hacks, rugs — things safe coin does not worry about.

Single-page static site for $SAFECOIN, terminal/ASCII style, including the
**SAFE DEFENSE PROTOCOL** minigame: drainers, hackers, rug pullers and quantum
bugs crawl toward the coin — click or tap them before they touch it.

## Files

- `index.html` — the whole site (markup, styles, game logic)
- `assets/safecoin.webp` — the coin pfp, used in the hero and as the game's coin

## Deploy

It's a plain static site: host it anywhere (GitHub Pages, Netlify, Vercel,
Cloudflare Pages). No build step.
